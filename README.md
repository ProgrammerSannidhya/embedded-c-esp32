# ESP32 Embedded C Projects

This repository contains my Embedded C projects using the ESP32 and ESP-IDF.

## Projects

### 1. LED Blinking

A basic ESP32 project that blinks an external LED connected through a breadboard.

**Hardware:**
- ESP32 DevKit
- LED
- Resistor
- Breadboard
- Jumper wires

**Software:**
- C
- ESP-IDF
- VS Code

## What I Learned

- ESP-IDF project structure
- Building an ESP32 project
- Flashing code to the ESP32
- Using GPIO pins
- Controlling an LED with C
- Basic Git and GitHub workflow
